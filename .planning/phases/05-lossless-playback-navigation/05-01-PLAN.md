<feature>
  <name>Wall-clock playback session model</name>
  <files>src/playback/session.ts, test/unit/session.test.ts</files>
  <behavior>
    Type contract — `PlaybackSession` interface:
      - subtitleId: string (deterministic subtitle identity, Phase-6 persist target)
      - fileName: string (for banner title — avoids a lookup round-trip)
      - startedAt: number (wall-clock anchor; position while playing = now - startedAt + offsetMs)
      - offsetMs: number (current sync offset snapshot; mirrors engine offset for display + Phase 6)
      - pausedElapsedMs: number | null (position WITHOUT offset frozen at pause; null while playing)

    Function contract (all pure, all return NEW objects — no in-place mutation):
      - createSession({ subtitleId, fileName, offsetMs, now }) → fresh playing session: startedAt = now, pausedElapsedMs = null
      - pauseSession(session, now) → frozen copy: pausedElapsedMs = now - startedAt; idempotent — pausing an already-paused session keeps the FIRST frozen value (mirrors engine pause() guard)
      - resumeSession(session, now) → playing copy: startedAt = now - pausedElapsedMs, pausedElapsedMs = null; idempotent — resuming an already-playing session returns an equal session (mirrors engine play() guard)
      - sessionElapsedMs(session, now) → display position INCLUDING offset: playing = (now - startedAt) + offsetMs; paused = pausedElapsedMs + offsetMs. May be negative when offset pulls before zero — callers that format clamp via formatElapsedHMS
      - updateSessionOffset(session, offsetMs) → copy with replaced offsetMs (runtime offset adjustment keeps session + banner in sync; engine receives its own setOffset separately in Plan 05-04)
      - formatElapsedHMS(ms) → "h:mm:ss": hours unpadded and unbounded, minutes/seconds zero-padded two digits, sub-second floored, negative ms clamped to "0:00:00"

    Test cases (input → expected):
      - createSession(T): startedAt === T; pausedElapsedMs === null; subtitleId/fileName/offsetMs echoed
      - playing elapsed: created at T with offset 5000, queried at T+12000 → 17000
      - negative position allowed: elapsed = now - startedAt + offset can go below 0 (raw number returned)
      - pause freezes: play from T, pause at T+60000 (offset 0) → elapsed stays 60000 when queried at T+90000 and T+3600000
      - resume continuity: pause at 60000, resume at wall-time T+3600000 → elapsed at resume instant === 60000; at T+3605000 → 61000
      - resume-with-offset preserves PLAY-08 shape: offset −2500, 600s absence → elapsed = now - startedAt + offset (597500 for concrete injected nows)
      - double-pause keeps first frozen value; double-resume returns equal object
      - updateSessionOffset: elapsed shifts by the delta immediately (5000 → 8000 raises display by 3000)
      - formatElapsedHMS: 0 → "0:00:00"; 999 → "0:00:00"; 60000 → "0:01:00"; 452000 → "0:07:32"; 3599000 → "0:59:59"; 3600000 → "1:00:00"; 5025000 → "1:23:45"; 90061000 → "25:01:01"; -5000 → "0:00:00"
  </behavior>
  <implementation>
    Mirror PlaybackEngine's absolute-anchor discipline (PATTERNS.md §7): anchor once, never accumulate, never read a clock inside the module. JSDoc on the module states the dual-source rule — wall-clock Date.now() anchors the SESSION (survives view switches, later survives reloads); monotonic performance.now() stays the engine's sole cue-timing source — citing PATTERNS.md lines 350-364 as the design basis. Small, unexported helpers only if they clarify (e.g., pad2 for formatting) — no dependencies.
  </implementation>
</feature>
