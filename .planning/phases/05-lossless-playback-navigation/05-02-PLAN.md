<feature>
  <name>Playback history-entry policy</name>
  <files>src/playback/playbackHistory.ts, test/unit/playbackHistory.test.ts</files>
  <behavior>
    Type contract:
      - `HistoryLike` interface — the minimal slice of window.history this policy needs: readonly state: unknown; pushState(state: unknown, unused: string): void; replaceState(state: unknown, unused: string): void; back(): void. Dependency injection keeps the module DOM-free and unit-testable (no jsdom dependency in this project's toolchain).
      - `PLAYBACK_ENTRY` — frozen shared marker object { view: 'playback' } (D-01's marker contract).

    Function contract:
      - isPlaybackEntry(state: unknown) → boolean: true iff state is a non-null plain-object-style value whose view field equals 'playback'. False for null, undefined, primitives, strings (including 'playback' itself), arrays, and objects with other view values. Structured clones (JSON round-trip) MUST match — popstate never hands back the identical reference.
      - enterPlaybackHistory(h) → void (D-01 + D-02): if isPlaybackEntry(h.state) → h.replaceState(PLAYBACK_ENTRY, '') (re-entry: refresh marker, no stacking); else → h.pushState(PLAYBACK_ENTRY, '') (fresh entry over base or foreign state).
      - exitPlaybackHistory(h) → void (D-03): if isPlaybackEntry(h.state) → h.back() (consume exactly our marker so selection-page back exits the app naturally); else → no-op (nothing of ours on top; foreign/base history untouched).

    Test cases (FakeHistory maintains an internal array so depth is assertable):
      - fresh entry from base null state: depth 1 → 2, new top isPlaybackEntry
      - re-entry with marker already on top: depth unchanged, top still marker, exactly one replace (pause→play path of D-02)
      - entry over foreign top {custom:'x'}: pushes — foreign entry still sits underneath, unchanged
      - double-enter in a row: depth grows by exactly ONE total
      - exit with marker on top: one back() consumed; new top === the pre-playback entry
      - exit with null top: no back() — call count stays 0
      - exit with foreign top: no back() — foreign entry untouched
      - isPlaybackEntry truth table: true for PLAYBACK_ENTRY and for JSON.parse(JSON.stringify(PLAYBACK_ENTRY)); false for null / undefined / 0 / 'playback' / [] / {} / { view: 'selection' } / { view: 'playback', extra: 1 } is TRUE (field check, extra fields tolerated)
  </behavior>
  <implementation>
    ~40 LOC: interface + frozen marker + field-check + two policy functions with JSDoc citing D-01/D-02/D-03 line references from 05-CONTEXT.md. No imports. The marker constant is exported so App.tsx (05-04) and tests share one source of truth for the entry shape.
  </implementation>
</feature>
