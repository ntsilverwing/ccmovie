# Phase 5 — UI Design Contract

> Visual and interaction contract for Lossless Playback Navigation (PLAY-08).
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Locked decisions from `05-CONTEXT.md` D-01–D-09 are binding; this contract fills their
> visual/copy details and agent-discretion items prescriptively.

## Design System

| Property | Value |
|----------|-------|
| Tool | none — manual CSS classes in `src/index.css` |
| Preset | not applicable (tailwind/shadcn deliberately excluded per CONTEXT `code_context`: "CSS 类名 + index.css（无 Tailwind）") |
| Component library | none — hand-rolled class families (`.control-button`, `.back-button`, `.saved-movie-*`) |
| Icon library | none — text glyphs only (`‹`, `×`), matching existing `.saved-movie-delete` / `.back-button` precedent |
| Font | `system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`; time/digits use `monospace` (existing `.cue-time` / `.offset-display` pattern) |

**Cinema luminance rule (overrides all visual choices):** app is used in dark theaters at minimum
brightness. No new surface may exceed `#222` fill; no pure-white fills; emphasis is achieved by
luminance + weight only, never by saturated color (sole exceptions: existing semantic green
`#4caf50` wake-lock chip and playback-only `#FFD700` subtitle high-contrast — both out of Phase 5 scope).

## Typography

Font family: existing stacks (see Design System). Exactly **3 sizes, 2 weights**.

| Role | Size | Weight | Line Height | Used by |
|------|------|--------|-------------|---------|
| Body | 16px (1rem) | 400 | 1.5 | `.session-toast` message |
| Label | 13.6px (0.85rem) | 400 | 1.2 | `.playback-back` text (`‹ 返回` / `‹ Back`) |
| Meta | 12px (0.75rem) | 400 | 1.2 | Banner elapsed/paused line — `font-family: monospace`, tabular digits |
| Heading | 16px (1rem) | 500 | 1.2 | Banner movie title; Resume CTA label |

Rules:

- **No new font sizes.** Back control reuses `.control-button` size (13.6px) but NOT its bg/border (see Color).
- Hierarchy inside the banner = weight (500 title vs 400 meta) + luminance (`#e0e0e0` title vs `#888` meta), never size.
- Subtitle display typography (36–72px) is playback-content, unchanged and out of scope.
- zh and en share the same sizes — zh glyphs at 16px remain glanceable at arm's length in darkness.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#000000` | Page + playback background (existing OLED black) |
| Secondary (30%) | `#111111` (fills) / `#222222` (active fills) | `.session-banner` bg, `.session-toast` bg `rgba(17,17,17,0.95)`, resume CTA bg `#222`, dismiss bg `transparent`, all borders `#333` |
| Accent (10%) | `#ffffff` on `#e0e0e0` elements | **Resume CTA only:** text `#fff`, border `1px solid #666`, weight 500 — the single highest-luminance interactive element of the phase; plus `.session-toast` body text `#e0e0e0` |
| Destructive | `#331111` fill + `#ffffff` text — **`:active` state only** | Banner dismiss ×: idle = `#888` glyph on transparent (no red visible in theater); pressed reveals `#331111`/`#fff`. Mirrors existing `.saved-movie-delete:active` exactly. |

Accent reserved for: **(1) banner Resume CTA label+border, (2) toast message text, (3) banner movie
title (`#e0e0e0`).** Nothing else. Back control is explicitly *de-emphasised* (see below) and may
NOT use accent luminance at idle.

**Back control low-visual-weight treatment (D-09):**

| State | Style |
|-------|-------|
| Idle | text-only `‹ 返回`; color `#888`; background `transparent`; border `none`; opacity `0.55` |
| Active/pressed | opacity `1`; color `#e0e0e0` |
| Auto-hide | hidden with `.playback-controls` after existing 3s inactivity timer (no extra styling) |

Semantic colors unchanged this phase: `#4caf50` (wake-lock chip), `#4caf50` warning banner `#332200`,
error banner `#331111`, `#FFD700` high-contrast subtitle (playback content only). Dim/high-contrast
body classes recolor subtitle text ONLY — banner/toast/back-control colors are unaffected on the
selection page.

## Copywriting Contract

Bilingual via `t(key)` — new keys appended to `src/i18n/translations.ts` (en/zh pairs mandatory).

| Element | Key | en | zh | Source |
|---------|-----|----|----|--------|
| Primary CTA — banner resume | `resumePlaying` | `Resume` | `继续播放` | D-06 一键续播按钮 |
| Back control visible label | reuse `back` (prefix `‹ `) | `‹ Back` | `‹ 返回` | CONTEXT discretion (文字按钮家族) |
| Toast message (after playback→selection, any path) | `sessionKeptToast` | `Subtitle kept — resume anytime` | `原字幕已保留，可直接继续播放` | **zh locked in REQUIREMENTS PLAY-08** |
| Banner meta, playing | `sessionElapsed` | `{time} elapsed` | `已播 {time}` | D-06 已播时长 |
| Banner meta, paused | `sessionPausedAt` | `Paused at {time}` | `已暂停 {time}` | Wall-clock rule: frozen value when status = paused |
| Dismiss aria-label | `dismissSession` | `Abandon session` | `放弃本次播放` | D-08 关闭 = 放弃会话 |
| Resume aria-label | `resumePlaying` + `fileName` | `Resume {fileName}` | `继续播放《{fileName}》` | a11y context |
| Empty state heading | — | *(unchanged)* `Import an SRT file to get started` | *(unchanged)* `导入 SRT 文件开始使用` | No session → selection page is byte-identical to v1.0; no banner, no toast |
| Error state | — | *(no new surface)* | *(no new surface)* | Phase 5 adds no failure modes; fullscreen/wakelock rejections stay silent per existing `.catch(() => {})` pattern |

**Time format:** `h:mm:ss` (hours unpadded, minutes/seconds zero-padded — e.g. `0:07:32`, `1:23:45`),
monospace digits, computed as `now − startedAt + offset` when playing, frozen at pause.

**Destructive actions (single — confirmed):**

| Action | Confirmation | Rationale |
|--------|--------------|-----------|
| Dismiss "continue playing" banner × (= stop + abandon session) | **NONE — single tap** | D-09 principle applied app-wide ("确认弹窗、双击、长按均被明确否决——可逆性优先"); precedent: `.saved-movie-delete` has had zero confirmation since v1.0 and user accepted. Mis-tap cost = re-select movie + `±0.5s` re-sync; accepted as locked by D-08. |

All other actions (back, resume, system-back intercept) are fully reversible → no confirmation anywhere in this phase. Zero dialogs.

## Interaction Contract (Phase 5 scope)

| # | Interaction | Contract |
|---|-------------|----------|
| I-1 | Tap back control (playback) | Single tap → selection view. No confirm/double-tap/long-press (D-09). Engine keeps clocking; `exitFullscreen()` + release Wake Lock (D-04). |
| I-2 | Android system back gesture/key (playback) | `popstate` on pushed `{view:'playback'}` entry → identical landing to I-1 (D-01). Toast fires on every playback→selection transition regardless of path. |
| I-3 | System back on selection page | Natural app exit, no interception, no confirm (D-03). |
| I-4 | Toast lifecycle | passive — `pointer-events: none`, `role="status"`, auto-fade after **3500ms** (within locked 3–4s band), `0.3s` opacity transition (matches `.playback-controls` transition). |
| I-5 | Banner resume tap | → playback view at `now − startedAt + offset`; Wake Lock + fullscreen re-acquired inside the tap gesture chain (D-05, reuses `handlePlay` pattern). |
| I-6 | Banner dismiss tap | Stop + abandon session; banner removed; no confirm (see destructive table). |
| I-7 | Elapsed tick | Banner meta refreshes every **1000ms** while playing; frozen while paused; banner unmounts when engine transitions `→ idle` (e.g. natural auto-stop, per CONTEXT discretion #4). |
| I-8 | Controls re-display on re-entry | Existing 3s auto-hide timer resumes unchanged (CONTEXT discretion #3). |
