# Phase 6 — UI Design Contract

> Visual and interaction contract for Session Persistence & Resume (FILE-03).
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> This phase introduces **zero new visual language**. Per Phase 5 lock D-07, the
> resume card is the same position + same component base as `SessionBanner`; Phase 6
> layers IndexedDB provenance + expiry semantics on top — no relocation, no restyle.

green `#4caf50` wake-lock chip and playback-only `#FFD700` subtitle high-contrast — out of scope).

high-contrast subtitle (playback content only). Dim/high-contrast body classes affect subtitle
text only — card colors are unaffected on the selection page.

## Copywriting Contract

Bilingual via `t(key)` — **all keys exist in `src/i18n/translations.ts` (en/zh) since Phase 5;
Phase 6 adds zero new copy** (research assumption A5: verbatim reuse accepted). If planning later
wants persisted-source-distinct wording, keys are additive-only and must be appended in en+zh pairs.

| Element | Key | en | zh | Source |
|---------|-----|----|----|--------|
| Primary CTA — card resume | `resumePlaying` (existing) | `Resume` | `继续播放` | RESEARCH A5 + D-07 (same component base, same CTA) |
| Resume aria-label | `resumePlayingAria` (existing) | `Resume {fileName}` | `继续播放《{fileName}》` | a11y context, existing |
| Card meta, playing-at-kill | `sessionElapsed` (existing) | `{time} elapsed` | `已播 {time}` | RESEARCH A5 |
| Card meta, paused-at-kill | `sessionPausedAt` (existing) | `Paused at {time}` | `已暂停 {time}` | Existing key; used when persisted record carries `pausedElapsedMs` |
| Dismiss aria-label | `dismissSession` (existing) | `Abandon session` | `放弃本次播放` | D-08 关闭 = 放弃会话 |
| Empty state heading | — | *(unchanged)* `Import an SRT file to get started` | *(unchanged)* `导入 SRT 文件开始使用` | No record / expired / invalid record → selection page byte-identical to v1.0; no card |
| Error state | — | *(no new surface)* | *(no new surface)* | Corrupt record, DB load failure, and dead soft-link all resolve to silent card removal (see UI Considerations). Gesture-chain rejections (fullscreen/wake lock) stay silent per existing `.catch(() => {})` pattern. |

**Time format:** `h:mm:ss` (hours unpadded, minutes/seconds zero-padded — e.g. `0:07:32`, `1:23:45`),
monospace digits, computed as `now − startedAt + offset` for un-paused records, frozen at the
recorded `pausedElapsedMs` for paused records. Negative clock skew clamps to `0:00:00` via the
existing `formatElapsedHMS` display clamp (research Pitfall 8) — card must never render a negative
or `NaN` time.

**Expiry threshold copy:** none. The threshold value (`SESSION_EXPIRY_MS`, default 6h, finalized
at planning) is **never surfaced in the UI** — no countdown, no "expires in N hours", no stale
warning. Expired sessions present exactly as no session: byte-identical v1.0 selection page.

**Destructive actions (single — confirmed):**

| Action | Confirmation | Rationale |
|--------|--------------|-----------|
| Dismiss resume card × (= delete the IndexedDB session record + remove card) | **NONE — single tap** | D-08 locked: dismiss = abandon, one mental model across banner and card; 影院场景可逆性优先，确认弹窗/双击/长按均被否决 (05-CONTEXT specifics). Mis-tap cost = re-import/re-select + manual re-sync; accepted by D-08. |

All other actions (resume tap, app relaunch, new import replacing the record) are fully
reversible or state-replacing → no confirmation anywhere in this phase. Zero dialogs.

## Interaction Contract (Phase 6 scope)

| # | Interaction | Contract |
|---|-------------|----------|
| I-1 | App load with persisted record | Mount-effect `loadSession()` → shape-validate → `isSessionExpired(session, now, expiryMs)` → valid record drives card; expired/invalid → record cleared, selection page byte-identical to v1.0. No loading spinner: card simply appears when the async load resolves (IndexedDB read is sub-frame-to-tens-of-ms). |
| I-2 | Card resume tap | `enableWakeLock()` synchronously FIRST (iOS gesture chain, existing `handlePlay` convention), then async cue lookup (id → `by-fileName` fallback → abandon), then imperative restore: `setCues → play() → seekTo(sessionElapsedMs(session, now))` (research Pattern 3, ordering locked). Card removed on success. |
| I-3 | Resume tap with dead soft-link | Cue lookup misses both id and fileName → record deleted, card removed silently. No error toast, no dialog (D-08 anti-friction). |
| I-4 | Card dismiss tap | Delete IndexedDB record + remove card, single tap, no confirm (see destructive table). Selection page returns to byte-identical v1.0 state. |
| I-5 | New subtitle import while card visible | Existing `handleImport → stop()` path clears the record; card removed. The new session (when played) writes its own record — replacement is automatic, no UI affordance needed. |
| I-6 | Card vs. SessionBanner exclusivity | Card renders only when hook `session === null` (post-relaunch); `SessionBanner` renders only when hook session exists. Mutually exclusive by construction — never both visible (research Pitfall 2). |
| I-7 | Card elapsed tick | Mirrors banner ticking semantics: 1000ms interval re-reads `Date.now()` only while the persisted record is un-paused (`pausedElapsedMs` absent); paused records render the frozen value with no interval armed. |
| I-8 | Playing tick write silence | Engine position ticks NEVER write to IndexedDB and NEVER re-render the card beyond the I-7 1s tick. Writes occur only on session-object identity change (create/pause/resume/offset/stop). |

## UI Considerations

> Shape-rooted state coverage per the ui-consideration probe. Empty/error copy lives in the
> Copywriting Contract above; this table resolves state coverage.

Applicable state considerations resolved: **8 covered, 0 backstop, 0 unresolved**

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | resume card | ✅ covered | No persisted record, expired record, or invalid record → card renders nothing; selection page byte-identical to v1.0 (Copywriting: empty-state row). |
| populated | resume card | ✅ covered | Valid un-paused record: title `#e0e0e0` 500 + `{time} elapsed` meta in `#888`, wall-clock value at render, 1s tick (I-7). |
| partial | resume card (paused-at-kill) | ✅ covered | Record carries `pausedElapsedMs`: meta switches to `Paused at {time}` with the frozen value, no tick; CTA unchanged; resume tap restores PLAYING from the frozen position (research Open Question 3 recommendation: land playing). |
| loading | resume card | ✅ covered | `loadSession()` is the only async surface; card simply appears on resolve. No spinner/skeleton — a transient loading chrome would flash in a dark theater for a sub-100ms read. |
| error | record load / cue rehydration | ✅ covered | Corrupt record → validate-fail → treated as absent + best-effort clear (silent). DB load failure → warn-logged, treated as absent (persistence failure ≠ app failure). Dead soft-link on resume → silent record clear + card removal (I-3). No error UI exists by design. |
| overflow | card meta digits | ✅ covered | `monospace` unbounded hours (`24:00:00+`) flexes in `flex:1; min-width:0` text block (inherited `.session-banner*` geometry). |
| zero-one-many | resume card | ✅ covered | Cardinality is 0‖1 — single-record store keyed `'current'` (v1 single-session model); plural copy not applicable. |
| long-text | card movie title | ✅ covered | Single line: `white-space: nowrap; overflow: hidden; text-overflow: ellipsis` (inherited `.session-banner-title`). |
