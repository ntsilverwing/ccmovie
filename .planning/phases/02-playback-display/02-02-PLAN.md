**src/components/SubtitleDisplay.tsx:**
- Props interface: `{ cue: Cue | null, fontSize: number, isDimmed: boolean }`
- Renders a full-viewport container div with centered text:
  - Container: `ref={containerRef}`, className `"subtitle-container"`
  - Text: className `"subtitle-text"`, renders `cue?.text ?? ''` as React text node (never dangerouslySetInnerHTML)
- `useEffect` for font size: `containerRef.current?.style.setProperty('--subtitle-font-size', `${fontSize}px`)` — updates CSS custom property directly (no re-render needed for visual change)
- `useEffect` for dim mode: `document.body.classList.toggle('dimmed', isDimmed)` with cleanup `return () => document.body.classList.remove('dimmed')`
- Component re-renders only when cue content changes (parent controls this via activeCue from usePlaybackEngine)

**src/components/PlaybackControls.tsx:**
- Props interface: `{ status: PlaybackStatus, onPlay: () => void, onPause: () => void, onStop: () => void, fontSize: number, isDimmed: boolean, onFontSizeChange: (size: number) => void, onDimToggle: () => void }`
- Renders controls overlay (positioned fixed at bottom center):
  - Start button (shown when status === 'idle'): large touch target, calls onPlay, min 120x56px
  - Pause/Resume button (shown when status === 'playing' || 'paused'): toggles between pause() and play()
  - Stop button (shown when status !== 'idle'): calls onStop
  - Font size slider: `<input type="range" min="36" max="72" value={fontSize} onChange={e => onFontSizeChange(Number(e.target.value))}>` with className `"font-size-slider"`
  - Dim mode toggle: button showing "Dim: On/Off" state, calls onDimToggle
- All buttons have adequate touch targets for dark theater use (min 48x48px)
- Import PlaybackStatus type from usePlaybackEngine
