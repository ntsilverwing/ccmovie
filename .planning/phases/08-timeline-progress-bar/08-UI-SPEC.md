# Phase 8 — UI Design Contract (Timeline & Progress Bar)

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| 时间标签 — 当前时间（左） | 0.85rem (13.6px) | 400 | 1.2 |
| 时间标签 — 总时长（右） | 0.85rem (13.6px) | 400 | 1.2 |
| Body（app 全局基线，本阶段不改） | 1rem (16px) | 400 | 1.5 |
| Heading / Display | N/A — Timeline 不渲染任何标题或展示级文字 | — | — |

**Rules:**
- 本阶段**只引入一个新字号**：`0.85rem`（对齐既有 `.control-button` 的 `font-size: 0.85rem`）；Body 行为 app 既有基线，仅登记不改动。
- Weight 合同：**400** 是 Timeline 全部文字的唯一字重。**500** 仅存在于 app 层既有元素（`--subtitle-font-weight: 500`、`.session-banner-resume`），Timeline **不得**引入新字重。
- 时间标签使用 `font-family: monospace` + `min-width: 7ch`，保证 `h:mm:ss` 定宽、播放中无水平抖动。
- 时间标签可加 `font-variant-numeric: tabular-nums`（monospace 下冗余但无害）。

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#000000` | 播放视口背景（OLED 黑，既有） |
| Secondary (30%) | `#111` / `#222` | 控制面板按钮底色（既有 `.control-button` / `.start-button`，本阶段不改） |
| Accent (10%) | `#e0e0e0` | **仅限**：① 已播放段填充 ② 拖拽手柄 ③ 当前时间标签 |
| Destructive | N/A | 本阶段无破坏性操作，不引入 destructive 色 |

**Accent reserved for:** 已播放段填充（`linear-gradient` 的 `#e0e0e0` 段 / Firefox `::-moz-range-progress`）、拖拽手柄 thumb、当前时间标签。**禁止**用于：未播放轨道、密度标记、总时长标签、任何装饰性高亮（D-05：不把 Timeline 设计成高亮彩色主视觉）。

**Timeline 组件色板（完整映射）:**

| Element | Value | Source |
|---------|-------|--------|
| 已播放段填充 | `#e0e0e0` | D-05「现有高对比度白色」= 既有正文白 `#e0e0e0` |
| 未播放轨道 | `#333` | D-05 暗灰色，对齐既有 `#333` border 色阶 |
| 密度标记基色 | `#555` | RESEARCH.md Pattern 5 |
| 密度标记 tier-1（低密度） | `#555` @ `opacity: 0.35` | D-08 三档亮度·低 |
| 密度标记 tier-2（中密度） | `#555` @ `opacity: 0.65` | D-08 三档亮度·中 |
| 密度标记 tier-3（高密度） | `#555` @ `opacity: 1.0` | D-08 三档亮度·高 |
| 拖拽手柄（thumb） | `#e0e0e0`，`opacity: 0`（静止）→ `1`（hover/active/focus-visible/拖拽中） | D-06 |
| 当前时间标签 | `#e0e0e0` | 活动信息用正文白 |
| 总时长标签 | `#888` | 次要信息用既有 muted 灰 |
| Focus outline | `1px solid #666`, `outline-offset: 4px` | 键盘可达性，暗场低亮度 |

**静态色板规则（锁定）：** Timeline 颜色为**硬编码静态值，不绑定 `var(--subtitle-color)`**。`body.dimmed`（`#888888`）与 `body.high-contrast`（`#FFD700`）两个 body class 是**字幕文本专用** token（DISP-03 / WCAG AAA scope），Timeline 不随动——若高对比模式把进度条染成金色，将违反 D-05「不做成高亮彩色主视觉」。D-05 所指「现有高对比度白色」即 `#e0e0e0` 本身。

| Element | Copy |
|---------|------|
| Primary CTA | **none** — Phase 8 不新增任何按钮；交互 = range 输入上的拖拽与键盘操作（播放/暂停按钮为既有元素，不属于本阶段文案） |

| `timelineLabel` | `Playback progress` | `播放进度` |

**A11y 数值朗读模式（D-13 锁定）：**

### 布局合同

- Timeline 是 PlaybackControls `playing/paused` 分支的**第一个子元素**，`flex-basis: 100%` → 在既有按钮行之上独占一整行（`.playback-controls` 已有 `flex-wrap: wrap`）【default 决策：进度条置于控制簇顶部为播放器惯例】
- 行内结构：`[当前时间] [轨道区 flex:1] [总时长]`，`gap: 8px`
- 命中区扩展不改变布局：`padding: 16px 0; margin: -16px 0`（D-11），垂直命中 ≥ 48px
- 层叠顺序（z-order，D-08 锁定）：密度标记层 (z:0) < 已播放段填充（track 背景）< 透明 range 输入层
- 横屏压缩：既有 `@media (orientation: landscape) and (max-height: 500px)` 只缩窄轨道可用宽度，**不新增** Timeline 专属横屏规则
- 拖拽期间控制区可见性沿用既有 `controlsVisible` 机制；Phase 8 **不修改**自动隐藏逻辑（Phase 10 UI-08 范围）

### 密度分桶合同（D-07/D-08/D-09）

- `bucketCount = 100`（default；CONTEXT.md 授权实现者按 `totalDurationMs` × 轨道宽度裁量，但**一经确定即固定**，保证标记数量稳定）
- 半开区间 `[start, end)`；cue 跨桶界时 `floor(start/bucketMs)` 至 `floor((end-1)/bucketMs)`（Pitfall 7 防溢出）
- **三档映射（本 spec 裁定，修正 RESEARCH.md Pattern 4 草案公式）：** 草案 `ceil(count/max*2)` 只产生 2 个非空档位，与 D-08「低、中、高三档亮度」冲突。锁定为确定性阈值映射：
  - `count === 0` → `tier 0`（不渲染 DOM，D-09）
  - `ratio = count / max`；`ratio <= 1/3` → `tier 1`；`ratio <= 2/3` → `tier 2`；否则 `tier 3`
  - CSS 类：`.tier-1` / `.tier-2` / `.tier-3`（opacity 0.35 / 0.65 / 1.0，见色板）
- 低密度桶**永不**提升为最高亮度（D-09）

### 交互合同

| 输入 | 行为 | 持久化 |
|------|------|--------|
| `pointerdown` 于 range | `isDragging=true`；`dragValue=displayValue`；thumb 立即可见（D-06） | 无 |
| 拖拽中 `onChange` | `dragValue = clamp(v)`；`onPreviewSeek(clamp(v, 0, totalMs - 1))` —— **预览目标钳到 `totalMs - 1`** 防引擎中途自动停止导致 Timeline 卸载（Pitfall 2）；画面（时间/字幕）实时刷新（D-01/D-03） | **零**（不逐帧写 IndexedDB，D-01） |
| `pointerup` | `isDragging=false`；`onSeek(dragValue)` —— 提交路径**不钳**末端（命中精确 `totalMs` = 合法立即结束，07-D-03） | 一次（经既有 hook persist effect） |
| 兜底提交 | `onBlur` / `onPointerLeave` 时若 `isDragging` 仍为 true → 同 `pointerup` 提交（A2 缓解：个别浏览器不派发 pointerup） | 一次 |
| `keydown ←/→` | `preventDefault()` 拦截原生步进；`onSeek(clamp(v ± 5000ms))` 直接提交（D-12；**禁止** `step=5000` —— 会吸附拖拽，Pitfall 3） | 一次/按键 |
| `Home/End/PageUp/PageDown` | 原生行为 → 触发 `onChange` 且无 pointerdown → `handleChange` 走「非拖拽 → 直接提交」分支（Pitfall 5） | 一次 |
| 拖拽中受控值 | `value = dragValue`（手势主权，位置 ticker 不回灌）；非拖拽 `value = clamp(sessionElapsedMs(session, now), 0, totalMs)`（双时钟规则：显示只读 session wall-clock） | — |
| 位置刷新 | 播放态 250ms interval + fill 无 transition（渐变填充不可插值，接受 250ms 阶梯更新）【default；RESEARCH Open Question 1，真机不达标再议 rAF，禁新增依赖】 | — |
| 静止态 | thumb `opacity: 0`；hover / active / focus-visible / 拖拽中 → `opacity: 1`，`transition: opacity 0.15s ease`（D-06/D-11） | — |
| 触摸 | `touch-action: none` 于输入元素（防滚动干扰拖拽，A1）；`-webkit-tap-highlight-color: transparent`（对齐既有按钮） | — |
| 禁用态 | `totalDurationMs <= 0` → 原生 `disabled`，禁用态不渲染密度标记 | — |

**明确禁止（Anti-Patterns，来自 RESEARCH.md，执行者不得偏离）：**
1. 拖拽预览调既有 `seek()`（每帧写 IndexedDB，违反 D-01）
2. `step=5000` 实现键盘步进（吸附拖拽）
3. 拖拽中把时钟值灌入受控 `value`（thumb 回跳）
4. Timeline 内直接调 `saveSession`（持久化只属于 hook 语义变化 effect）
5. 密度标记绘制在已播放段之上（违反 D-08 层级）
6. 显示值读 engine 内部时钟（违反双时钟规则）
7. 为组件测试引入 jsdom / @testing-library（违反零依赖约束；组件行为走真机人工验证清单）
