## 拖拽反馈方式

| Option | Description | Selected |
|--------|-------------|----------|
| 实时预览 | 拖动过程中立即更新时间、字幕和播放位置；松手后完成一次 Session 持久化 | ✓ |
| 松手后定位 | 拖动过程中只显示临时位置，松手时才更新引擎和字幕 | |
| 分段预览 | 拖动时更新位置预览，但仅在达到一定时间间隔后刷新字幕 | |

**User's choice:** 实时预览
**Notes:** 拖动过程中不逐帧持久化，提交时保存最终位置。

## Timeline 视觉层级

| Option | Description | Selected |
|--------|-------------|----------|
| 细线高亮 | 细轨道配高亮已播放段，保持低亮度、低干扰 | ✓ |
| 粗轨道手柄 | 使用较粗的触控轨道和明显拖拽手柄 | |
| 原生 range | 优先使用原生 range 外观 | |
| 低调常显手柄 | 静止时保留小型位置指示点 | |
| 仅操作时显现 | 静止时隐藏手柄，触摸/拖动/悬停后显示 | ✓ |
| 仅保留轨道 | 不显示独立手柄，只用已播放段末端表示位置 | |
| 白色与暗灰 | 已播放段白色，未播放段暗灰 | ✓ |
| 白色与黑色 | 未播放段尽量融入纯黑背景 | |
| 主题色与暗灰 | 已播放段使用主题色 | |

**User's choice:** 细线高亮；手柄仅操作时显现；已播放白色、未播放暗灰。
**Notes:** 视觉需适配影院暗场。

## Cue 密度标记规则

| Option | Description | Selected |
|--------|-------------|----------|
| 固定时间桶聚合 | 按固定时间区间聚合字幕数量，标记数量稳定 | ✓ |
| 每条字幕一个标记 | 保留每条 Cue 的时间位置 | |
| 活动区间 | 只绘制字幕存在的区间 | |
| 亮度分级 | 根据桶内 Cue 数量使用低、中、高三档亮度 | ✓ |
| 等宽标记 | 每个时间桶使用相同亮度 | |
| 高度分级 | 通过标记高度表达密度 | |
| 标记置底 | 密度标记作为背景，进度显示优先 | ✓ |
| 标记置顶 | 标记始终保持最显眼 | |
| 播放后隐藏 | 已播放区域标记逐渐隐藏 | |
| 空桶不绘制 | 无 Cue 的桶保持透明 | ✓ |
| 空桶绘制暗线 | 所有时间桶都有结构线 | |
| 单条也用最高亮度 | 有字幕即使用明显标记 | |

**User's choice:** 固定时间桶聚合、亮度分级、标记置底、空桶不绘制。
**Notes:** 空档应继续保持清晰可见，标记服务于导航而非装饰。

## 移动端触控与可访问性

| Option | Description | Selected |
|--------|-------------|----------|
| 原生 range | 使用 input type=range 提供稳定触控、键盘和屏幕阅读器语义 | ✓ |
| 自定义 ARIA slider | 完全控制轨道与手柄视觉，自行维护交互语义 | |
| 原生加视觉层 | 原生 range 负责交互，非交互层绘制密度标记和轨道 | ✓ |
| 5 秒键盘步进 | 左右方向键每次移动 5 秒 | ✓ |
| 1 秒键盘步进 | 更精细但操作次数更多 | |
| 按 Cue 跳转 | 每次移动到上一/下一条字幕 | |
| 当前时间/总时长 | 例如“播放进度，1:12 / 2:05” | ✓ |
| 仅百分比 | 只暴露进度百分比 | |
| 当前 Cue 文本 | 同时读出当前字幕内容 | |
| 轨道可视、区域加大 | 保持细线视觉并提供更大透明触控区域 | ✓ |
| 仅细线可触摸 | 视觉与触控区域一致 | |
| 触摸时放大轨道 | 触摸期间临时放大轨道与手柄 | |

**User's choice:** 原生 range；视觉层与交互层分离；5 秒键盘步进；读屏显示当前时间/总时长；提供更大的透明触控区域。
**Notes:** 保持无障碍语义，同时不牺牲暗场下的命中率。
