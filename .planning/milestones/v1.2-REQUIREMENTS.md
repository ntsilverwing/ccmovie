# Requirements: CinemaSyncSubs v1.2

**Defined:** 2026-08-31
**Core Value:** 让非英语母语观众在影院看外语片时能跟上剧情

## v1 Requirements

### Engine Enhancement

- [x] **ENG-01**: PlaybackEngine 新增 `seek(targetMs)` 方法，播放中 Seek 无缝继续播放、暂停中 Seek 触发 `onCueChange` 实时更新字幕
- [x] **ENG-02**: Seek 后 Session 状态同步 — 重新锚定 `startedAt = now - (targetMs - offsetMs)`，确保刷新/杀进程后恢复到 Seek 后位置
- [x] **ENG-03**: 解析字幕时提取最后一条字幕的 `end` 时间作为总时长（`totalDurationMs`），供 Timeline 使用

### Timeline & Progress

- [x] **UI-01**: Timeline 进度条组件 — 支持拖拽定位，左侧显示当前时间、右侧显示总时长（复用 `formatElapsedHMS()`）
- [x] **UI-02**: Timeline 拖拽 Seek — 播放中拖拽更新 `startTime` 无缝继续，暂停中拖拽实时更新字幕，松手后持久化 Session
- [x] **UI-03**: Timeline 上显示 Cue 标记点 — 可视化字幕密度指示器

### Gesture Navigation

- [x] **UI-04**: 屏幕手势操作 — 上滑跳转下一句字幕、下滑跳转上一句字幕，同步更新进度条和内部时钟状态
- [x] **UI-05**: 手势提示 Overlay — 首次使用时显示一次性手势引导，可关闭

### Settings & Layout

- [x] **UI-06**: 播放控制区分层 — 主控制栏（Timeline + 播放/暂停 + 设置按钮），设置面板收纳低频操作
- [x] **UI-07**: 设置面板（Drawer）— 收纳字幕偏移（-0.5s/+0.5s/Reset）、字体大小、暗场模式、高对比度、全屏切换
- [x] **UI-08**: 控制栏自动隐藏 — 无操作 3 秒后自动隐藏，点击屏幕唤出

## Out of Scope

| Feature | Reason |
|---------|--------|
| 速度控制（Speed） | 与影院音频不同步 |
| 缩略图预览（Thumbnails） | 无视频流可用 |
| 跳过片头（Skip Intro） | 无元数据支持 |
| 字幕工具提示（Tooltip on scrub） | Nice-to-have，推迟到 v1.3+ |
| 触觉反馈（Haptic Feedback） | 低优先级，推迟 |
| 键盘快捷键 | 开发者便利，非核心 |
