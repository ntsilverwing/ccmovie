  <action>
Create the framework-agnostic PlaybackEngine class and the React usePlaybackEngine hook.

**src/playback/PlaybackEngine.ts:**
- Export a `findActiveCue(cues: Cue[], elapsed: number, hint: number): number` pure function implementing binary search with sequential hint optimization:
  - Fast path 1: check if still in current cue (hint index) → O(1)
  - Fast path 2: check next cue (most common transition) → O(1)
  - Fallback: binary search for cue where `cue.start <= elapsed < cue.end` → O(log n)
  - Return -1 when no cue is active
- Create `PlaybackEngine` class:
  - Constructor takes `cues: Cue[]` and `onCueChange: (index: number) => void` callback
  - Private fields: `startTime: number`, `isPlaying: boolean`, `rafId: number | null`, `lastIndex: number`, `cues: Cue[]`
  - `play()`: sets `startTime = performance.now()`, resets `lastIndex = -1`, sets `isPlaying = true`, calls `tick()`
  - `pause()`: cancels rAF via `cancelAnimationFrame`, sets `isPlaying = false`
  - `stop()`: cancels rAF, sets `isPlaying = false`, resets `lastIndex = -1`, calls `onCueChange(-1)`
  - `setCues(cues: Cue[])`: updates internal cues array
  - Private `tick()`: computes `elapsed = performance.now() - startTime`, calls `findActiveCue(cues, elapsed, lastIndex)`, if index changed calls `onCueChange(index)`, schedules next rAF via `requestAnimationFrame(tick)` if still playing
  - Auto-stop when elapsed exceeds last cue's end time (no active cue and all cues passed)

**src/hooks/usePlaybackEngine.ts:**
- Define `PlaybackStatus` type: `'idle' | 'playing' | 'paused'`
- Define `PlaybackState` interface: `{ status: PlaybackStatus, currentIndex: number, activeCue: Cue | null }`
- Define `PlaybackAction` union type: `{ type: 'PLAY' } | { type: 'PAUSE' } | { type: 'STOP' } | { type: 'TICK'; activeIndex: number; cues: Cue[] }`
- Create `playbackReducer(state, action)` pure function:
  - PLAY → `{ ...state, status: 'playing' }`
  - PAUSE → `{ ...state, status: 'paused' }`
  - STOP → `{ status: 'idle', currentIndex: -1, activeCue: null }`
  - TICK → if `action.activeIndex === state.currentIndex`, return same state object (prevents re-render); else update currentIndex and activeCue
- Export `usePlaybackEngine(cues: Cue[])` hook:
  - `useReducer(playbackReducer, INITIAL_STATE)` for state
  - `useRef` for engine instance, rAF ID, startTime, lastIndex, cues (NOT useState — these don't affect rendering)
  - `useEffect` to keep cuesRef in sync with cues prop
  - `play/pause/stop` callbacks via `useCallback` that delegate to PlaybackEngine + dispatch
  - Cleanup on unmount: cancel rAF
  - Returns `{ state, play, pause, stop }`

**CRITICAL timing rules (from PITFALLS.md):**
- NEVER use setTimeout/setInterval for subtitle timing — they drift and throttle in background tabs
- NEVER use the rAF callback timestamp for timing — always call performance.now() inside tick (rAF timestamps can differ by up to 6ms due to VSync)
- NEVER accumulate frame deltas — use absolute `elapsed = performance.now() - startTime`
- NEVER store rAF ID in state — use useRef (state causes re-renders)
- NEVER dispatch TICK when active cue hasn't changed — reducer returns same state object

  - `updateSettings(partial: Partial<Settings>)` callback via useCallback that merges prev+partial, persists to localStorage, returns new state
  - Returns `{ settings, updateSettings }`

**src/App.tsx modifications:**
- Import usePlaybackEngine and usePersistedSettings
- Keep existing subtitle/error state and FilePicker/CuePreview for import view
- Add playback: `const { state: playbackState, play, pause, stop } = usePlaybackEngine(subtitle?.cues ?? [])`

- View state logic based on playbackState.status and subtitle:
  - **Import view**: No subtitle → render FilePicker (existing behavior)
  - **Ready view**: Subtitle loaded, status === 'idle' → render CuePreview + large Start button (min 48x48px touch target)
  - **Playback view**: status === 'playing' || 'paused' → render current cue text + controls overlay
