<task type="auto">
  <name>Task 1: Integrate Fullscreen API into playback lifecycle</name>
  <files>src/App.tsx</files>
  <action>
    Add Fullscreen API calls to the playback lifecycle in App.tsx:

    1. Add a `useRef` for the hide timer: `const hideTimerRef = useRef<ReturnType<typeof setTimeout>>()`

    2. Add a `controlsVisible` state: `const [controlsVisible, setControlsVisible] = useState(true)`

    3. Modify `handlePlay` to request fullscreen within the user gesture chain (same pattern as enableWakeLock):
       ```tsx
       const handlePlay = useCallback(() => {
         enableWakeLock()
         // Request fullscreen within user gesture to satisfy browser security
         if (!document.fullscreenElement) {
           document.documentElement.requestFullscreen?.().catch(() => {
             // Fullscreen not supported or denied — fail silently, playback continues
           })
         }
         play()
       }, [enableWakeLock, play])
       ```

    4. Modify `handleStop` to exit fullscreen when stopping playback:
       ```tsx
       const handleStop = useCallback(() => {
         disableWakeLock()
         if (document.fullscreenElement) {
           document.exitFullscreen?.().catch(() => {})
         }
         stop()
       }, [disableWakeLock, stop])
       ```

    5. Add a useEffect that manages the controls auto-hide timer during playback:
       ```tsx
       useEffect(() => {
         // Only auto-hide during active playback (not paused)
         if (playbackState.status !== 'playing') {
           setControlsVisible(true)
           return
         }
         setControlsVisible(true)
         const resetTimer = () => {
           setControlsVisible(true)
           clearTimeout(hideTimerRef.current)
           hideTimerRef.current = setTimeout(() => setControlsVisible(false), 3000)
         }
         resetTimer()
         window.addEventListener('pointermove', resetTimer)
         window.addEventListener('touchstart', resetTimer)
         return () => {
           clearTimeout(hideTimerRef.current)
           window.removeEventListener('pointermove', resetTimer)
           window.removeEventListener('touchstart', resetTimer)
         }
       }, [playbackState.status])
       ```

    6. Pass `controlsVisible` to PlaybackControls:
       ```tsx
       <PlaybackControls
         ...
         controlsVisible={controlsVisible}
       />
       ```

    Note: handlePause does NOT hide controls (user needs them to resume). handlePlay during 'paused' state should re-show controls (handled by the useEffect since status stays 'playing' only when actually playing — when paused the effect cleanup runs and resets to visible).

    IMPORTANT: Do NOT add `await` before requestFullscreen() — it must be fire-and-forget within the user gesture chain, same as enableWakeLock.
  </action>
