- `getNoSleep()` callback creates the instance on first use (NoSleep requires DOM)

- Return `{ enable, disable }`

Modify `src/App.tsx`:
- Import and use `useWakeLock` hook
- In the `play` handler (passed to PlaybackControls as `onPlay`), call `enableWakeLock()` synchronously within the click handler chain. - In the `stop` handler, call `disableWakeLock()`
- In the `pause` handler, optionally call `disableWakeLock()` (screen can sleep when paused — user is not watching)

The `onPlay` prop passed to `PlaybackControls` should be a wrapper that calls `enableWakeLock()` then `play()`. Similarly `onStop` should call `disableWakeLock()` then `stop()`.

Handle `visibilitychange` event: when the document becomes visible again after being hidden (user switched apps briefly), re-acquire Wake Lock if playback is still active. Add this in a useEffect that checks `playbackState.status === 'playing'`.
