  <files>src/components/PlaybackControls.tsx</files>
  <action>
    Restructure PlaybackControls.tsx to be responsive on landscape phones:

    1. Wrap the font-size slider in a container with a visible label. Replace the bare `<input type="range">` with:
       ```tsx
       <div className="font-size-control">
         <span className="font-size-label" aria-hidden="true">Aa</span>
         <input
           type="range"
           min="36"
           max="72"
           value={fontSize}
           onChange={(e) => onFontSizeChange(Number(e.target.value))}
           className="font-size-slider"
           aria-label="Font size"
           aria-valuetext={`${fontSize} pixels`}
         />
       </div>
       ```
       The "Aa" icon is a universal symbol for text size — visible in dark theater, no translation needed.

    2. Reduce button text verbosity. The current labels are: "−0.5s", "+0.5s", "Reset", "Stop", "Pause"/"Resume", "Dim"/"Bright", "Contrast"/"Normal". Keep these as-is — they're already concise. The fix is in CSS sizing, not label changes.

    3. No structural changes to the JSX layout order needed — the flex container with CSS fixes in Task 2 will handle overflow.

    Note: The `controlsVisible` prop was added in Plan 03. Keep it in the interface and destructuring. This task adds the font-size label wrapper only.

<task type="auto">
  <name>Task 2: Add responsive CSS constraints and reduce default font size</name>
  <files>src/index.css, src/hooks/usePersistedSettings.ts</files>
  <action>
    Fix the overflow with CSS and reduce the default font size:

    **index.css — `.playback-controls`:**

    1. Add `max-width: 90vw` and `overflow` handling:
       ```css
       .playback-controls {
         position: fixed;
         bottom: 24px;
         left: 50%;
         transform: translateX(-50%);
         display: flex;
         gap: 8px;
         align-items: center;
         z-index: 100;
         max-width: 90vw;
         flex-wrap: wrap;
         justify-content: center;
         transition: opacity 0.3s ease;
       }
       ```
       Changes: gap reduced from 16px to 8px, added max-width: 90vw, flex-wrap: wrap, justify-content: center.

    2. Reduce button sizing for landscape:
       ```css
       .control-button {
         min-width: 64px;
         min-height: 44px;
         padding: 8px 12px;
         font-size: 0.85rem;
         background: #222;
         color: #e0e0e0;
         border: 1px solid #444;
         border-radius: 8px;
         cursor: pointer;
       }
       ```
       Changes: min-width 88→64px, padding 12px 24px→8px 12px, font-size 1rem→0.85rem.

    3. Reduce offset display width:
       ```css
       .offset-display {
         min-width: 48px;
         text-align: center;
         font-family: monospace;
         font-size: 0.8rem;
         color: #e0e0e0;
         user-select: none;
         -webkit-user-select: none;
       }
       ```
       Changes: min-width 64→48px, font-size 0.9→0.8rem.

    4. Add font-size-control container and label styles:
       ```css
       .font-size-control {
         display: flex;
         align-items: center;
         gap: 6px;
       }
       .font-size-label {
         font-size: 0.9rem;
         color: #888;
         user-select: none;
         -webkit-user-select: none;
       }
       .font-size-slider {
         width: 100px;
         accent-color: #888;
       }
       ```
       Slider width reduced from 160px to 100px.

    5. Add a landscape media query to further compact on short screens:
       ```css
       @media (orientation: landscape) and (max-height: 500px) {
         .playback-controls {
           bottom: 12px;
           gap: 6px;
         }
         .control-button {
           min-width: 56px;
           min-height: 40px;
           padding: 6px 10px;
           font-size: 0.8rem;
         }
         .font-size-slider {
           width: 80px;
         }
       }
       ```

    **usePersistedSettings.ts:**

    6. Change the default fontSize from 48 to 36:
       ```ts
       const DEFAULT_SETTINGS: Settings = {
         fontSize: 36,
         isDimmed: false,
         offsetMs: 0,
         isHighContrast: false,
       }
       ```
       Rationale: 36px is the minimum of the range and reduces light pollution in dark cinemas. Users can still increase up to 72px if needed.

    Width calculation after fix: 7 buttons × 64px + 48px display + 100px slider + 8 gaps × 8px = 448 + 48 + 100 + 64 = 660px minimum. With flex-wrap as safety net, this fits all phone landscape viewports (667-932px). On very narrow screens, wrapping ensures nothing is cut off.
