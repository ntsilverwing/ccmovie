1. Create `src/imports/fileImport.ts` with:
   - Import detectAndDecode from './encoding'
   - Import parseSRT from './srtParser'
   - Import ParsedSubtitle type from '../types/subtitle'
   - Import ImportError from '../utils/errors'
   - `importSRT(file: File): Promise<ParsedSubtitle>` async function
   - Step 1: Validate file extension — extract extension via `file.name.toLowerCase().split('.').pop()`, must be 'srt' or 'txt', otherwise throw new ImportError('INVALID_TYPE', 'Please select an SRT or TXT subtitle file.')
   - Step 2: Validate file size — cap at 5MB (5 * 1024 * 1024 = 5242880 bytes), throw new ImportError('FILE_TOO_LARGE', 'File is too large. Maximum size is 5MB.') if exceeded
   - Step 3: Read file as raw bytes — `new Uint8Array(await file.arrayBuffer())`
   - Step 4: Call `detectAndDecode(buffer)` to get { text, encoding }
   - Step 5: Call `parseSRT(text)` to get ParsedSubtitle result
   - Step 6: Set result.metadata.fileName = file.name
   - Step 7: Set result.metadata.encoding = encoding
   - Step 8: Validate result — if result.cues.length === 0, throw new ImportError('NO_CUES', 'No subtitle cues found. The file may be corrupted or in an unsupported format.')
   - Step 9: If result.errors.length > 0, log warnings to console but still return result (partial success is acceptable)
   - Step 10: Return result

**Critical:** importSRT is the orchestrator. It does NOT implement encoding detection or parsing — it delegates to detectAndDecode (Task 2 in Plan 1) and parseSRT (Task 3 in Plan 1). This keeps each module focused on one responsibility and makes testing easier.
  </action>

    - Valid SRT file produces ParsedSubtitle with cues array populated

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-05 | Denial of Service | FilePicker | medium | mitigate | 5MB file size cap in importSRT prevents oversized file processing and memory exhaustion |
| T-01-06 | Tampering | CuePreview (subtitle text) | high | mitigate | Render all subtitle text via React text nodes (never dangerouslySetInnerHTML) — subtitle content from untrusted SRT files cannot inject HTML/JS |
