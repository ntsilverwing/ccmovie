**PlaybackEngine.ts** — Add timing offset support:
1. Add `private offsetMs: number = 0` property to the class.
2. Add a `setOffset(offsetMs: number): void` method that sets `this.offsetMs = offsetMs`. This is the ONLY way offset is applied — never modify cue data.
3. Modify `tick()` to compute `const elapsed = performance.now() - this.startTime + this.offsetMs`. The offset is added to elapsed (positive = subtitles appear later, negative = earlier).
4. Do NOT add offset to the auto-stop check — keep `elapsed >= this.cues[this.cues.length - 1].end` as-is since offset is already baked into elapsed.

**usePersistedSettings.ts** — Extend Settings interface:
1. Add `offsetMs: number` to the `Settings` interface with JSDoc: "Timing offset in milliseconds, range -5000 to 5000".
2. Add `isHighContrast: boolean` to the `Settings` interface with JDDoc: "High contrast mode — yellow text on black".
3. Update `DEFAULT_SETTINGS` to include `offsetMs: 0` and `isHighContrast: false`.
4. In `loadSettings()`, add validation for both new fields:
   - `offsetMs`: must be a number, clamped to [-5000, 5000]
   - `isHighContrast`: must be a boolean
   - Both fall back to defaults on invalid/missing data

**usePlaybackEngine.ts** — Wire offset from settings to engine:
1. Add a new `offsetMs` parameter to the hook signature: `usePlaybackEngine(cues: Cue[], offsetMs: number)`.
2. Add a `useEffect` that calls `engineRef.current?.setOffset(offsetMs)` whenever `offsetMs` changes. This ensures real-time offset updates during playback without restart.

**index.css** — Add high-contrast rule:
1. Add `body.high-contrast { --subtitle-color: #FFD700; }` after the existing `body.dimmed` rule.
2. The rule follows the exact same pattern as `body.dimmed` — a single CSS custom property override that propagates via cascade to all subtitle elements.
3. Do NOT add text-shadow overrides or glow effects — keep the existing shadow for consistency.
