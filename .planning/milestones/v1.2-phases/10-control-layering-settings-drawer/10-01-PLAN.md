# 10-01: Control Layering & Settings Drawer

## Objective
Refactor the playback interface into hierarchical layers according to Phase 10 design decisions (D-01 to D-11):
1. Independent Top Bar (`PlaybackTopBar`) containing Back button and Wake Lock indicator.
2. Minimalist Main Control Bar containing Timeline, Play/Pause, and Settings button.
3. Bottom Sheet Settings Drawer containing low-frequency controls: time offset (-0.5s/+0.5s/display), discrete font size buttons ([ A- ] / [ A+ ]), fullscreen toggle, stop, and global reset (offset 0 + default font size 48).
4. Auto-hide timer paused while settings drawer is open, tapping hidden screen wakes UI without toggling playback, and swipe provides visual timeline feedback.

## Requirements
- **UI-06**: 播放控制区分层 — 主控制栏（Timeline + 播放/暂停 + 设置按钮），设置面板收纳低频操作
- **UI-07**: 设置面板（Drawer）— 收纳字幕偏移（-0.5s/+0.5s/Reset）、字体大小、全屏切换，依 D-04 移除高对比度，依 D-06 改用 A-/A+ 离散按钮
- **UI-08**: 控制栏自动隐藏 — 无操作 3 秒后自动隐藏，点击屏幕唤出，依 D-03 展开抽屉时暂停倒计时

<must_haves>
  <truths>
    - Top Bar displays Back button and Screen ON indicator at the screen top, synchronized with controlsVisible.
    - Main control bar shows only Timeline, Play/Pause (or Start), and Settings toggle button.
    - Settings Drawer opens from the bottom as a dark bottom sheet when Settings button is clicked.
    - Drawer contains time offset controls, discrete [ A- ] and [ A+ ] font size buttons, fullscreen toggle, stop, and global reset.
    - High contrast toggle is completely removed from controls and drawer (D-04).
    - Global reset restores both offset to 0 and font size to default 48px (D-09).
    - Auto-hide 3-second timer is paused while Settings Drawer is open (D-03).
    - Tapping the screen while controls are hidden wakes controls without triggering play/pause (D-02).
    - All control buttons maintain minimum 48x48px touch targets for cinema accessibility.
  </truths>
  <prohibitions>
    - Do not trigger settings drawer on vertical swipe gestures (gestures only navigate subtitles).
    - Do not auto-hide controls while user has the settings drawer actively open.
    - Do not retain high contrast toggle in the drawer (prohibited by cinema etiquette D-04).
  </prohibitions>
</must_haves>
