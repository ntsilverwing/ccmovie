<threat_model>
<threat_assessment>
- **T-09-Conflict (手势与控件拖拽冲突)**: 用户拖拽 Timeline 或点击播放/设置按钮时可能被手势层拦截。防御措施：手势监听器挂载于 `.subtitle-container` 自身，Timeline 和 `.playback-controls` 在 DOM 结构和定位上完全独立于字幕容器，手势生效区域严格限定于中央黑屏字幕区（D-01）。
- **T-09-Gesture-PullRefresh (移动端默认下拉刷新打断手势)**: 移动端 Safari/Chrome 在快速下滑或下拉时可能触发页面滚动或刷新。防御措施：在 CSS 中为 `.subtitle-container` 设置 `touch-action: none`（D-01），并在 pointerdown 阶段执行 `setPointerCapture`，保证滑动事件完全由应用接管。
- **T-09-Flash (暗场刺眼光污染与视觉干扰)**: 引导层或跳转如果含有高对比度白色、高亮动画或剧烈闪烁，将破坏影院暗场体验。防御措施：严格执行 UI-SPEC 色板，使用 `rgba(0, 0, 0, 0.75)` 半透明暗色背景与 `#888888` / `#e0e0e0` 哑光文本，跳转无任何补间动画（D-12），引导层以 0.2s 平滑渐变。
</threat_assessment>

<action>
1. 创建 `src/hooks/useGestureNavigation.ts`，定义接口与 Hook：
   ```typescript
   export interface GestureNavigationOptions {
     onSwipeUp: () => void;
     onSwipeDown: () => void;
     enabled?: boolean;
   }

   export interface GestureContainerProps {
     onPointerDown: (e: React.PointerEvent<HTMLElement>) => void;
     onPointerMove: (e: React.PointerEvent<HTMLElement>) => void;
     onPointerUp: (e: React.PointerEvent<HTMLElement>) => void;
     onPointerCancel: (e: React.PointerEvent<HTMLElement>) => void;
   }
   ```
2. 在 Hook 内部管理触摸状态与指针引用：
   - `lastTriggeredRef = useRef<number>(0)`；
   - `startCoordRef = useRef<{ x: number; y: number } | null>(null)`；
   - `isPointerDownRef = useRef<boolean>(false)`；
3. 提供事件处理函数：
   - `onPointerDown(e: React.PointerEvent<HTMLElement>)`:
     - 若 `!enabled` 或 `e.button !== 0`（仅响应主按键或单指触控）则退出；
     - 记录起手坐标：`startCoordRef.current = { x: e.clientX, y: e.clientY }`；
     - `isPointerDownRef.current = true`；
     - `(e.currentTarget as HTMLElement).setPointerCapture(e.pointerId)` 锁定指针；
   - `onPointerMove(e: React.PointerEvent<HTMLElement>)`:
     - 若 `!isPointerDownRef.current || !startCoordRef.current` 则忽略；
     - 当垂直位移超过 40px 时，可阻止默认行为；
   - `onPointerUp(e: React.PointerEvent<HTMLElement>)`:
     - 若未处于 down 状态则退出；
     - 取出起手点坐标，计算终点坐标 `(e.clientX, e.clientY)`；
     - 调用 `detectGesture(startX, startY, endX, endY)`；
     - 若手势为 `'up'` 或 `'down'`：
       - 检查 `isGestureThrottled(Date.now(), lastTriggeredRef.current)`；
       - 若未被节流：更新 `lastTriggeredRef.current = Date.now()`，执行对应 `onSwipeUp()` 或 `onSwipeDown()` 回调；
     - 清除 `startCoordRef.current = null` 与 `isPointerDownRef.current = false`；
     - 尝试释放捕获 `(e.currentTarget as HTMLElement).releasePointerCapture(e.pointerId)`；
   - `onPointerCancel(e: React.PointerEvent<HTMLElement>)`:
     - 状态复位，清除坐标引用与 down 标记，释放指针捕获。
4. 返回 `{ containerProps: { onPointerDown, onPointerMove, onPointerUp, onPointerCancel } }` 供字幕区容器解构。
5. 运行 `npx tsc --noEmit` 保证类型无错。
</action>
