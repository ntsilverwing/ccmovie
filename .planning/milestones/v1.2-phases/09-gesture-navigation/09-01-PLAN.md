<threat_model>
<threat_assessment>
- **T-09-Math (输入非确定性与手势误触)**: 触摸起点与终点坐标可能含有 NaN、Infinity、超小抖动或斜向滑动。防御措施：`detectGesture` 显式校验坐标有效性，采用严格的大于判定 `absDeltaY > absDeltaX` 和 `absDeltaY >= 40`，任何平局或非数均返回 `null`。
- **T-09-Boundary (空档与越界计算溢出)**: 当前时间处于字幕首部前、尾部后、零字幕或超长空档时可能导致数组越界或死循环。防御措施：`findCueNavigationTarget` 前置短路空数组，采用二分法或线性检索找到当前所在或相邻 cue，首尾边界严格返回 `null`，确保无索引溢出。
- **T-09-Storage (无痕模式或存储配额异常)**: Safari 无痕模式或嵌入式 WebView 可能抛出 `SecurityError` 或 `QuotaExceededError`。防御措施：`hasSeenGestureGuide` 和 `markGestureGuideSeen` 使用防御性 `try/catch` 包装，降级为内存会话状态，保证应用不中断。
</threat_assessment>
</threat_model>

   ```typescript
   import type { Cue } from '../types/subtitle'

   export function findCueNavigationTarget(
     cues: readonly Cue[],
     currentTimeMs: number,
     direction: 'up' | 'down'
   ): number | null
   ```
   实现逻辑：
   - 若 `cues.length === 0` 返回 `null`；
   - 遍历或二分查找当前时间 `currentTimeMs` 命中的 active cue 索引（`c.start <= currentTimeMs && currentTimeMs < c.end`）；
   - 若命中某 cue（索引 `idx`）：
     - 若 `direction === 'up'`：若 `idx + 1 < cues.length` 返回 `cues[idx + 1].start`；否则返回 `null`（已到末尾）；
     - 若 `direction === 'down'`：若 `idx - 1 >= 0` 返回 `cues[idx - 1].start`；否则返回 `null`（已到第一句）；
   - 若未命中任何 cue（处于空档）：
     - 找到第一个满足 `c.start > currentTimeMs` 的 cue（后继 cue，索引 `nextIdx`）；
     - 找到最后一个满足 `c.end <= currentTimeMs` 的 cue（前驱 cue，索引 `prevIdx`）；
     - 若 `direction === 'up'`：若存在 `nextIdx`，返回 `cues[nextIdx].start`；否则返回 `null`（片尾空档）；
     - 若 `direction === 'down'`：若存在 `prevIdx`，返回 `cues[prevIdx].start`；否则返回 `null`（片头空档）；
