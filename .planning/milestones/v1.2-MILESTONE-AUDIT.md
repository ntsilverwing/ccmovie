## 4. Cross-Phase Integration & Wiring

Verified by `gsd-integration-checker`. 15 of 15 key interfaces **WIRED** end-to-end; 0 orphaned exports; 0 missing links.

### Key Connection Points

1. **Phase 07 → Phase 08**:
   - `PlaybackEngine.seek(targetMs)` and `usePlaybackEngine.previewSeek(targetMs)` wire directly into `Timeline.tsx` via `PlaybackControls`.
   - `previewSeek` calls `engineRef.current?.seek` without calling `setSession`, delivering **zero IndexedDB write amplification** during scrub.
   - `ParsedSubtitle.metadata.totalDurationMs` flows into `Timeline.tsx` for duration label and drag bounds clamping `[0, totalDurationMs]`.

2. **Phase 07 → Phase 09**:
   - `useGestureNavigation` triggers `usePlaybackEngine.seek(targetMs)`, which re-anchors engine wall-clock and triggers single-shot session persistence.
   - `findCueNavigationTarget` correctly hops across cues and blank gaps using Phase 07 cue data structure.

3. **Phase 08 & Phase 09 → Phase 10**:
   - `Timeline` occupies top row of `PlaybackControls` (`flex-basis: 100%`).
   - Swipe cue jump triggers temporary 2.0s flash feedback of controls/timeline without disrupting auto-hide countdown.
   - Swipe gestures on `.subtitle-container` (`touch-action: none`) suppress spurious auto-hide timer resets.

4. **Phase 10 TopBar & Controls Layering**:
   - Back button and Wake Lock lifted into `PlaybackTopBar` at screen top.
   - Screen tap while controls hidden wakes controls without triggering play/pause.
   - Drawer open state pauses 3s auto-hide countdown; drawer close resumes countdown.
