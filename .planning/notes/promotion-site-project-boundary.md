## 决定

为 CinemaSyncSubs 单独创建非 PWA 推广站项目 `ccmovie-site`，与现有播放器 PWA 作为同级目录和独立 Git 仓库维护。

## 边界

- 现有 `ccmovie` 项目继续专注于字幕播放器 PWA。
- `ccmovie-site` 负责品牌介绍、用户痛点、解决方案和引导用户开始使用的 CTA。
- 推广站与播放器使用同一品牌，通过同一主域名下的不同二级域名连接。
- 两个项目独立部署和发布；推广文案或外链更新不应要求发布播放器。
- 推广站不做 PWA。

## 演进方向

推广站 MVP 不做长期内容发布或聚合搜索。它可先提供人工筛选、可信的字幕库外链目录；字幕聚合搜索须在确认合法数据源、授权或正式 API 后再评估，避免将反爬和合规风险带入 MVP。
